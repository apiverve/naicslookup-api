# NAICS Lookup API - Dart/Flutter Client

NAICS Lookup is a NAICS code lookup and search API for the 2022 North American Industry Classification System. Look up one code or up to 500 at once, or search by keyword, and get the title, description, level, parent, hierarchy and children, while paid plans add the SBA small-business size standard, the Census index terms, cross-references and the 2017 concordance.

[![pub package](https://img.shields.io/pub/v/apiverve_naicslookup.svg)](https://pub.dev/packages/apiverve_naicslookup)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This is the Dart/Flutter client for the [NAICS Lookup API](https://apiverve.com/marketplace/naicslookup?utm_source=dart&utm_medium=referral&utm_content=readme).

## Installation

Add this to your `pubspec.yaml`:

```yaml
dependencies:
  apiverve_naicslookup: ^1.2.6
```

Then run:

```bash
dart pub get
# or for Flutter
flutter pub get
```

## Usage

```dart
import 'package:apiverve_naicslookup/apiverve_naicslookup.dart';

void main() async {
  final client = NaicslookupClient('YOUR_API_KEY');

  try {
    final response = await client.execute({
      'code': '541511',
      'search': 'software publisher',
      'level': 6,
      'details': true,
      'limit': 10
    });

    print('Status: ${response.status}');
    print('Data: ${response.data}');
  } catch (e) {
    print('Error: $e');
  }
}
```
